# 打包与分发说明（Win10/11）

适用：把 WorldExecutor 交给同事/朋友（Win10 或 Win11 64 位）。

## 系统要求（Win10/11 通用）

| 项 | 要求 | 说明 |
|---|---|---|
| 系统 | Windows 10 1809+ / Windows 11 | PySide6 6.11 最低 Win10 1809 |
| 架构 | x64 | 依赖 wheel 均为 win_amd64 |
| Python | 3.12+（推荐 3.14） | m7 任务要求 >=3.12（PEP 701 f-string） |
| 管理员权限 | 任务中心真机操作需要 | 启动脚本自动提权（bat RunAs）；非管理员任务中心明确拒绝并提示 |
| Git | 仅首次准备 m7 需要 | setup_m7 克隆官方仓库用 |

## 分发形态 A：源码包（推荐，最简单）

1. 打包 `world_executor/`（不含 `m7_venv/`、`m7/`、`runtime.db`、`logs/`、`.env`——gitignore 已覆盖）
2. 接收方运行 `启动世界执行器.bat`：
   - 自动检测/创建 `m7_venv`（py -3.14/3.13/3.12 自动找）+ 装依赖
   - 自动 `tools/setup_m7.py`：克隆 m7 官方仓库到**项目内 `m7/`** + 同步依赖
3. 启动后：宝箱收集链可用；任务中心可用（m7 子进程）

## 分发形态 B：exe 打包（可选，工程量大）

- `WorldExecutor.spec` 已瘦身（去掉 m7 通知专用依赖 opencc/playsound3/winotify）
- **注意**：任务中心子进程需要 `m7_venv\Scripts\python.exe`（或 exe 目录便携
  `python314/python.exe`）与项目内 `m7/`——exe 分发必须**捆绑**这两项：
  ```
  发布目录/
    WorldExecutor.exe
    m7/               # m7 源码（运行时副本）
    python314/        # 便携 Python（子进程解释器，可选——不捆绑则要求系统 Python 3.12+）
    config.yaml 等
  ```
- `_FROZEN` 分支已支持 exe 目录内 `m7/` 优先 + `March7thAssistant` 兜底

## 常见坑

1. **Python 3.14 生态**：requirements 已锁 3.14 兼容版（numpy 2.5.2/opencv 5.0/
   PySide6 6.11.1）——升级前先确认 cp314 wheel，否则 pip 源码编译必失败
2. **m7_venv 必须装两类依赖**：world_executor `requirements.txt` + m7 的
   `requirements.txt`（排除 pylnk3——见 `m7_requirements_nopylnk.txt`，
   setup_m7 已处理）；只装前者 → 任务中心子进程 import 崩
3. **pylnk3 投毒包**：m7 官方 requirements 含 pylnk3——quarantine stub 已挡
   （m7_launcher 注入），**不要**安装真实 pylnk3
4. **m7 更新**：项目内 `m7/` 无 .git——任务中心"更新 m7 模块"走外部镜像
   （`March7thAssistant/` 有 .git 时）git pull 后 robocopy 同步回项目内
5. **.env**：含真实 API key——分发前删除（.env.example 是模板）
