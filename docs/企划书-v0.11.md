## 二、GUI State ≠ Runtime State（显示边界铁律）

- runtime 状态机冻结（11 态，含内部态），GUI 显示层压缩（8 主状态 + overlay 事件）。
- 未来 runtime 可能出现 `NAVIGATING_EDGE / MOVEMENT_CORRECTION / LANDMARK_SEARCH` 等内部态，GUI 一律映射到 NAVIGATING。
- **GUI 是人看的，不是调试全部状态**；全部状态进 Replay，不全进界面。

## 三、Runtime Replay 提前至 M0（v0.10 最重要新增）

Replay 不是 GUI 功能，是**调试基础设施**。第一批就定义统一事件：

```
runtime/events/
  schema.py     # 事件类型 + 字段定义（冻结）
  bus.py        # 事件总线（线程安全，可订阅/持久化）
```

事件 schema（冻结）：

```json
{
  "id": "evt_001",
  "execution_id": "run001",
  "time": 12345,
  "type": "state_changed",
  "from": "NAVIGATING",
  "to": "RECOVERING",
  "context": {
    "room": "corridor_A",
    "portal": "door_B",
    "reason": "arrival_failed"
  }
}
```

事件类型（首批冻结）：

| type | 说明 |
|---|---|
| `run_started` / `run_finished` | 会话生命周期 |
| `state_changed` | 状态迁移（from/to/context） |
| `observation` | 观测记录（见 §四 Observation Contract） |
| `action_executed` | 步骤执行（move/click/portal/…） |
| `target_progress` | 目标队列进度（target_id/status） |
| `fail_recorded` / `repair_recorded` | fail_log / repair_log 镜像 |

- 事件总线落盘 → runtime.db（events 表），GUI 只是**播放器**。
- Replay 数据生成在 M0（dry_run + 真机共用同一总线），GUI-M0.1 只显示实时流，M0.3 做回放界面。

## 四、修正 1：Observation Contract（冻结格式）

所有视觉/观测结果**必须**进入统一格式，禁止各自打印/各自记录：

```json
{
  "observer": "template_match",
  "target": "door_A",
  "confidence": 0.91,
  "timestamp": 123456,
  "context": {
    "room": "corridor_A",
    "world_state": "quest_done"
  }
}
```

契约字段（冻结）：

- `observer`：template_match / ocr / ui_signal / inferred / manual
- `target`：观测对象（door_A / in_combat / menu_open / room_id …）
- `confidence`：0~1（inferred/manual 允许 null）
- `timestamp`：毫秒
- `context`：room / world_state / portal 等环境快照（可选）

runtime/db.py 的 `record_state_observation` 改为按此契约写入；所有模板/OCR 调用点统一走 `observer` 通道。

## 五、修正 2：Knowledge 目录规范（compiler 输出不可手改）

```
knowledge/
  raw/        # 上游素材：视频事件清单、VLM 输出（只读输入）
  source/     # 手写/人工确认的源知识（人可改）
  compiled/   # compiler 产物（禁止手改，validator 强制检查生成者标记）
  patches/    # 补丁层：运行时 repair 的落盘补丁（优先级最高）
```

- `compiled/` 内文件带生成者标记（`"generated_by": "compiler-v0.1", "generated_at": ...`），validator 检测到"compiled 文件被手改"→ error。
- 优先级：patches > compiled > source。
- 现状迁移：`knowledge/black_tower_test` 为**手写测试包**，归属 source/（Sprint 0 不动结构，M0 compiler 上线时迁移目录）。
