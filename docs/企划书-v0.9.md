# M7H·WorldExecutor 企划书 v0.9（GUI 补充版·WorldExecutor Studio）

> 《崩坏：星穹铁道》地图知识执行引擎 —— 个人自用项目
> v0.8.1（工程冻结）→ **v0.9：可视化界面补充企划，Sprint 0 与 M0 并行推进**
> 原则：**技术栈参考三月七，视觉与交互大改到原作者认不出来**

---

## 〇、背景与定位

Sprint 0 的 dry_run/validator 均为 CLI，无法承担三件事：

1. **可观测性**：状态机迁移、房间判定、Portal 过渡全程黑盒，无法快速定位"为什么卡住"。
2. **知识包工作流**：视频 → VLM → 模板 → 知识包的手工链路缺少可视化辅助（模板质检、bbox 复核、图检查）。
3. **最终形态**：M1 真机调试与 M2 新地图扩展依赖 GUI 支撑，CLI 不可持续。

v0.9 将 GUI（代号 **WorldExecutor Studio**）纳入工程，但**严守冻结边界**：不改 runtime 状态机、不改知识包协议、不改执行逻辑；GUI 是观察窗 + 控制台 + 工作室，不是第四层架构。

## 一、技术栈与差异化铁律

| 维度 | 三月七助手 | WorldExecutor Studio |
|---|---|---|
| 框架 | PySide6 + PySide6-Fluent-Widgets | 同左（复用，不重造轮子） |
| 窗口 | MSFluentWindow 左导航列表页 | 无边框 + 顶部命令栏 + 左 IconBar（图标级导航） |
| 配色 | 粉色系（三月七形象） | **黑塔深蓝 #0F1B2D / 青金 #4FD1C5 / 琥珀警示**，暗色为主 |
| 品牌 | 三月七吉祥物 | 罗盘/星图徽标（黑塔空间站风） |
| 页面 | 主页/跃迁/工具/工作流/设置/日志 | 指挥台/世界图/观测/知识库/工作室/设置 |
| 核心差异 | 任务调度（daily/power/…） | **状态机实时可视化 + 房间图 + 观测审计**（三月七完全没有） |

**大改清单（认不出要点）**：
- 主色、字号、圆角、图标体系全换；所有页面组件重写，不复用三月七的 interface/card 代码。
- 导航从"文字列表"改为"图标条 + 顶部面包屑"。
- 无三月七式"任务开关卡"；改用**目标队列**（宝箱清单 + 状态徽标）。
- 新增三类三月七不存在的视图：状态机迁移动画、Room State Graph、观测时间线。

## 二、信息架构

```
WorldExecutor Studio
├── 指挥台 (Command Deck)         ← 默认页：会话控制 + 状态机实时图 + 目标队列
├── 世界图 (World Graph)           ← 房间节点图：房间=节点 / Portal=边 / 当前位置高亮
├── 观测 (Observation)             ← state_observation 时间线 + fail_log/repair_log 审计
├── 知识库 (Knowledge Library)     ← 知识包文件树 + validator 结果 + 模板网格
├── 工作室 (Studio)                ← 离线工具：视频分析 / 模板提取 / bbox 复核 / 模型探测
└── 设置 (Settings)                ← 引擎配置（三月七路径 / VLM 模型 / 界面）
```

**数据流**：
```
runtime 事件总线 (QSignal) ──→ 指挥台状态机动画
runtime.db (轮询 1s)     ──→ 观测时间线 / 目标队列徽标 / 统计
knowledge/ (QFileSystemWatcher) → 知识库文件树 + validator 自动重跑
studio 工具 (独立线程)   ──→ 进度条 → 产物写 ingest/raw/ + knowledge/
```

## 三、页面规格

### 3.1 指挥台（核心）
- 顶部：会话控制条 —— 「开始收集」大按钮 / 暂停 / 停止 / 单目标调试下拉。
- 中左：**状态机实时图**：11 个状态节点横向泳道，事件箭头高亮，当前状态脉冲动画；迁移日志滚动条。
- 中右：**目标队列**：knowledge 当前包内所有宝箱 → 状态徽标（待命/执行中/完成/失败/跳过），进度环（如 3/10）。
- 底部：**当前观测快照**：最近一条 state_observation（value+observer+confidence），房间判定卡。

### 3.2 世界图
- QGraphicsView 节点图：房间=圆角卡片（显示观察模板缩略图），Portal=青金连线（双箭头 + transition 类型），当前位置节点发光。
- 点击节点 → 右侧详情卡（房间 id / 关联宝箱 / 出入 portal）。
- 缩放/平移/自动布局（树形 + 力导向两种布局切换）。

### 3.3 观测
- 时间线流：state_observation 逐条滚动（类型色标：combat 红 / portal 青 / arrival 绿 / menu 灰 / world 蓝）。
- 过滤条：按 target_id / state_key / observer_type 过滤；置信度滑块。
- fail_log / repair_log 并排面板，失败截图可点击放大。

### 3.4 知识库
- 左：知识包树（knowledge/ 下所有包 + 文件）。
- 右：当前包 validator 输出（error/warn 红黄高亮）+ 图检查摘要（房间数/portal 数/宝箱数/连通性）。
- 模板网格：包内 templates/ 全部缩略图 + 文件名 + 尺寸；双击打开。

### 3.5 工作室（离线工具入口，跑在后台线程）
- 视频分析：选视频 → 抽帧参数 → 进度条 → 结果落 ingest/raw/frames/。
- 模板提取：跑 bbox 裁剪 → 预览网格 → 勾选转正式模板。
- 模型探测：一键重跑 probe_models.py 显示 OK/NO_QUOTA 状态表。
- B站下载：BV 号输入 → 分P 列表 → 选 P 下载 → 进度。

### 3.6 设置
- 引擎：March7thAssistant 路径、窗口标题匹配、config.yaml 生成按钮。
- VLM：API key（掩码显示）/ 主模型 / fallback 链（从 probe 结果下拉）。
- 界面：主题色 / 暗色亮度 / 日志保留 / DB 路径。
- 数据：runtime.db 打开位置 / 清空执行历史。
