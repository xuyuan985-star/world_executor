## 一、项目定位

**WorldExecutor（世界执行器）**：以《崩坏：星穹铁道》为验证场的游戏世界执行框架——用"世界状态理解 + 知识包执行"替代"AI 看画面瞎操作"。首个插件目标：黑塔空间站全宝箱半自治收集。

技术基座：**March7thAssistant**（上游开源，提供窗口自动化/OCR/模板匹配能力）；**Qwen 视觉 API**（qwen3-vl-plus，运行时 VLM 观测通道）；**PySide6 + Fluent**（WorldExecutor Studio GUI）。

核心分层：

```
Knowledge → Compiler → Runtime → api/events → Studio/GUI
                            ↑
                        Observer ← World
```

铁律：VLM 只理解不控制；Observer 只观测不下令；GUI 只走 api；运行时零 VLM 决策。

## 三、关键阻碍与处置（17 项已归档）

严重度分布：critical ×1 / high ×6 / medium ×6 / low ×4（详见 `failure_reports/20260808_185949_session_all_issues/`）

**核心教训：**

1. **UIPI 输入注入拦截（critical）**：普通权限进程向高权限游戏窗口注入输入被系统拒绝（SendInput ret=0，pyautogui 光标不动）。解法与 March7th 官方一致：pyuac 管理员提权。**当前唯一阻塞项。**
2. **同名双窗口 bug（high）**：March7th 按 title 抓窗口会抓到隐藏实例（客户区 0x0）→ 自建 win_capture 枚举可见窗口规避。
3. **pylnk3 投毒包 + 混淆 payload（high）**：安全事件已审计（防破解/免责校验，非数据窃取）；stub 绕过，不装真包。
4. **Windows 前台锁 / 遮挡 / PrintWindow 对 DX 失效（high）**：真机截屏必须窗口前台可见；已建立"激活→预热帧→mss 客户区"链路，激活失败自动报告。
5. **VLM 幻觉风险（medium）**：输入画面错误时高置信误报 → OCR+VLM 双通道交叉验证 + 置信度门槛 + C.1 两次独立观测。
